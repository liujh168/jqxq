# jqxq

中国象棋 UCI 引擎。回看这些开发记录，断断续续竟已走过多年，真是十年一梦。

![电影与现实](电影与现实.jpg)

## 项目简介

jqxq 是一个以 Stockfish 搜索框架为参考开发的中国象棋引擎，包含走法生成、局面搜索与评估，并逐步加入开局库、残局评估和多线程支持。

## 主要功能

- 支持 UCI 通信，并兼容部分象棋软件的局面与分数格式。
- 支持迭代加深、置换表、历史启发、杀手着法及多种搜索剪枝。
- 提供中国象棋走法生成、合法性检查、循环检测和 `perft` 测试。
- 支持内置、本地及云端开局库；云端查询可配置代理。
- 包含知识型残局评估及位置、子力等局面评估。
- 支持多线程搜索。

## 开发历程（精简）

- **2007—2008**：完成棋盘与棋子数据结构、着法生成、解将及将军步生成；逐步实现 UCCI 通信、搜索和静态搜索，形成可用的单机引擎。
- **2009—2010**：重构搜索流程，加入置换表、历史启发、杀手着法、空着剪枝等机制；开始采用多线程方案，并持续改进循环检测和搜索稳定性。
- **2013—2014**：升级开发环境，整理代码结构，继续向 Stockfish 的模块组织方式靠拢。
- **2016**：重写走法生成器并完善 `perft` 测试；整理 `Position` 与搜索代码，修复合法性、循环检测和搜索中的问题；开始完善局面评估、残局处理和多线程。
- **2017**：完善开局库管理，支持配置文件、内置／本地／云端查询；整合残局评估，并为配合 ncch 增加自定义消息等接口。
